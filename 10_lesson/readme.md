# Автоматизированные UI‑тесты для веб‑приложений

Проект содержит набор автоматизированных UI‑тестов для веб‑приложений, 
реализованных с использованием Python, Selenium WebDriver, PyTest и Allure.

## Структура проекта
# Python-
    ├── 10_lesson/
    │    │
    │    ├── allure-results                      # Директория для файлов отчетов
    │    ├── pages/                              # Папки с классами Page Object для разных страниц приложения
    │    │    │
    │    │    ├── __init__.py                    # Инициализирующий файл
    │    │    ├── AuthorizationPage.py           # Страница авторизации
    │    │    ├── CardShopPage.py                # Страница корзины
    │    │    ├── InformPage.py                  # Страница информации для оформления заказа 
    │    │    ├── ProductsListPage.py            # Страница товаров
    │    │    ├── profile_calc_page.py           # Калькулятор с задержкой
    │    │    └── SummaryPage.py                 # Страница обзора заказа
    │    │
    │    │
    │    ├── readme.md                           # Документация
    │    ├── test_calc_allure.py                 # Тест калькулятора с задержкой
    │    └── test_shop_allure.py                 # Тест процесса покупки в интернет‑магазине
    │
    │ 
    ├── README.md                                # Документация
    ├── conftest.py                              # Файл со списком фикстур
    └── requirements.txt                         # Список зависимостей проекта
          
## Предварительные требования

Перед запуском тестов убедитесь, что у вас установлены:

* Python версии 3.8 или выше.
* Менеджер пакетов `pip`.
* Веб‑браузеры:
  * Google Chrome (для теста калькулятора);
  * Mozilla Firefox (для теста интернет‑магазина).

## Команды для запуска тестов с отчетом Allure

* Запуск тестов   
   ```bash
   python -m pytest --alluredir=allure-results --clean-alluredir

* Открытие отчета
   ```bash
   C:\tools\allure\allure-2.46.0\bin\allure.bat serve allure-results
